# Editor integration

## Neovim

[spark.nvim][nvim] is a Neovim plugin that drives Spark from the editor, so you
can pick a template and generate a project without leaving Neovim.

See the plugin's repository for installation and configuration:
<https://github.com/pwnxpl0it/spark.nvim>.

[nvim]: https://github.com/pwnxpl0it/spark.nvim
